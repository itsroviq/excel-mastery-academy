# Excel Mastery Academy 📊

**Learn Microsoft Excel from Beginner to Professional Level.**

Excel Mastery Academy is an interactive, self-paced learning application designed to help learners master Microsoft Excel through structured lessons, practical exercises, assessments, and real-world projects.

The application covers essential Excel skills, from basic spreadsheet operations to advanced formulas, data analysis, automation, and professional business applications.

## ✨ Features

- **36 Structured Lessons** — Learn through four progressive learning levels.
- **Interactive Learning** — Explore lessons and practice Excel concepts.
- **Practical Exercises** — Reinforce your understanding with hands-on activities.
- **Assessments** — Test your knowledge and track your learning progress.
- **Real-World Projects** — Apply Excel skills to practical business scenarios.
- **Learning Dashboard** — Monitor your progress and achievements.
- **Formula Cheat Sheet** — Quickly review useful Excel formulas.
- **Review Tools** — Revisit previously learned topics.
- **Progress Backup & Restore** — Export and import your learning progress.
- **Responsive Design** — Access the application on desktop, tablet, or mobile.
- **Dark Mode** — Choose a comfortable learning appearance.

## 📚 Learning Curriculum

The curriculum is organized into four levels:

| Level | Category | Main Topics |
|---|---|---|
| 1 | Beginner | Excel interface, worksheets, cells, formatting, basic calculations, and essential functions |
| 2 | Intermediate | Logical functions, conditional calculations, lookup functions, text and date functions, and conditional formatting |
| 3 | Advanced | XLOOKUP, dynamic arrays, PivotTables, dashboards, Power Query, and VBA basics |
| 4 | Professional | Payroll, attendance, inventory, sales analysis, data cleaning, reporting, and business dashboards |

## 🚀 Getting Started

You can run the application locally or deploy it using GitHub Pages.

### Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start learning!

### Deploy with GitHub Pages

1. Fork or create a repository using this project.
2. Upload the application HTML file.
3. Rename the file to `index.html`.
4. Open your repository's **Settings**.
5. Navigate to **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose the `main` branch and `/ (root)` folder.
8. Click **Save**.

## 💾 Progress Storage

Learning progress is saved locally in your browser using Local Storage.

**Important:**
- Progress is stored on the device and browser where you use the application.
- Clearing browser data may remove saved progress.
- Use the backup and restore feature to preserve or transfer your learning progress.
- Progress is not automatically synchronized between devices.

## 🛠️ Technologies
